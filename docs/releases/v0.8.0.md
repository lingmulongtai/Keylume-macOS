# Keylume macOS v0.8.0 Preview

ホームで音源を選び、テスト演奏を再生すると、メロディーや和音に合わせて画面の鍵盤が動きます。3曲のオリジナルMIDIを収録しました。お持ちのMIDIファイルも読み込めます。

- **Rain on Glass** — 静かな分散和音で打鍵の強弱を聴く
- **Pocket Swing** — 歩くベースと短い和音でアタックを聴く
- **Lantern Waltz** — 三拍子のフレーズと最後の和音で余韻を聴く

内蔵音源 **Modeled Grand** は、打鍵から弦の振動を計算する物理モデリング・ピアノです。ハンマーの硬さ、弦の余韻、共鳴の強さを調整でき、追加ダウンロードなしで演奏できます。

macOS 13.3 以降の Apple Silicon／Intel に対応します。

- インストーラを使う場合は PKG を開いてください。`/Applications/Keylume.app` にインストールされます。[PKG をダウンロード](https://github.com/lingmulongtai/Keylume-macOS/releases/download/v0.8.0/Keylume_0.8.0_universal.pkg)
- 手動でインストールする場合は DMG を開き、Keylume.app を「アプリケーション」にドラッグしてください。[DMG をダウンロード](https://github.com/lingmulongtai/Keylume-macOS/releases/download/v0.8.0/Keylume_0.8.0_universal.dmg)

PKG は未署名です。両形式のアプリはアドホック署名済みで、Apple の公証は受けていません。
