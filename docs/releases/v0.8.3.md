# Keylume macOS v0.8.3 Preview

- サイドバーの「GitHubリポジトリ」から Mac 版のソースとリリースを標準ブラウザで開けます。
- **ピアノの操作**を整理しました。電源の横でオン・オフを確認でき、音作りはその下の独立した行から開けます。
- **Modeled Grand の高音**で、ハンマーが当たった瞬間の響きと弦の余韻を調整しました。ホームの「選ぶ」から Modeled Grand に切り替えて試せます。
- **MIDIの曲名**を読み込み時に決められます。ホームと「演奏」のどちらでも、拡張子を除いたファイル名が最初に入り、Enter で確定できます。編集した名前は再生画面にも反映されます。
- **Macのホーム画面**を、鍵盤と再生操作が中心のレイアウトに変更しました。サイドバーには macOS 26 以降で Liquid Glass を使い、ライト・ダークの外観と「透明度を下げる」設定に対応しています。

macOS 13.3 以降の Apple Silicon／Intel に対応します。

- インストーラを使う場合は PKG を開いてください。`/Applications/Keylume.app` にインストールされます。[PKG をダウンロード](https://github.com/lingmulongtai/Keylume-macOS/releases/download/v0.8.3/Keylume_0.8.3_universal.pkg)
- 手動でインストールする場合は DMG を開き、Keylume.app を「アプリケーション」にドラッグしてください。[DMG をダウンロード](https://github.com/lingmulongtai/Keylume-macOS/releases/download/v0.8.3/Keylume_0.8.3_universal.dmg)

PKG は未署名です。両形式のアプリはアドホック署名済みで、Apple の公証は受けていません。
