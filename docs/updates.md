# Mac版の更新

設定の「今すぐ確認」またはメニューバーの「アップデートを確認」で更新を調べられます。自動確認を有効にすると、起動後と12時間ごとにこのリポジトリの GitHub Releases を確認します。

現在より新しいバージョンに `Keylume_<version>_universal.dmg` が公開されると、リリースページを案内します。「Preview 版も通知する」を無効にするとプレリリースを除外します。更新時は DMG の Keylume.app をアプリケーションフォルダにコピーしてください。設定とプリセットはユーザーの Application Support に保存されます。
