# Mac版の更新

設定の「今すぐ確認」またはメニューバーの「アップデートを確認」で更新を調べられます。自動確認を有効にすると、起動後と12時間ごとにこのリポジトリの GitHub Releases を確認します。

現在より新しいバージョンに `Keylume_<version>_universal.dmg` が公開されると、リリースページを案内します。「Preview 版も通知する」を無効にするとプレリリースを除外します。リリースページで PKG または DMG を選べます。更新するには Keylume を終了し、PKG のインストーラを実行するか、DMG の Keylume.app を「アプリケーション」にドラッグして置き換えてください。設定とプリセットはユーザーの Application Support に保存されます。
